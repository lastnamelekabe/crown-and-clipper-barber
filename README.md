# Crown & Clipper Barber Co.

Live website: https://crown-and-clipper-barber.vercel.app

The deployable Next.js app is in [`crown-clipper-vercel/`](crown-clipper-vercel/). Vercel uses that directory as its Root Directory and deploys the `main` branch automatically.

To run it locally:

```bash
cd crown-clipper-vercel
npm ci
npm run dev
```

See [the app README](crown-clipper-vercel/README.md) for photo and barber name editing, booking, the first visit coupon, and publishing details.
